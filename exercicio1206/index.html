Introdução ao CSS

Autor: João da Silva

CSS é uma linguagem utilizada para definir a aparência visual das páginas web.

Com CSS podemos alterar cores, fontes, tamanhos e diversos outros aspectos visuais.

Vantagens do CSS

  • Separação entre conteúdo e aparência
  • Facilidade de manutenção
  • Maior organização do código

Aprender CSS é um passo importante para quem deseja desenvolver sites.
